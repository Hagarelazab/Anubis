# Anubis

Ancient Egyptian Collagen Database

Bioinformatics project for collagen peptide analysis across species.

## Components

R Shiny Dashboard
- Interactive exploration of collagen peptide data

Python Analysis
- Peptide scoring
- Species mapping
- Dataset processing

## Data files

step2_peptide_species_map.csv  
step2_peptides_with_species.csv  
step3_species_summary.csv  
step3_unique_peptides_scored.csv
